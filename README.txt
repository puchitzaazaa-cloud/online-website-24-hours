ONLINE WEBSITE PROJECT
ผู้จัดทำ: Puchit Khamsolpha

ไฟล์ในโปรเจกต์
- index.html : โครงสร้างหน้าเว็บไซต์
- style.css  : รูปแบบ สี และการจัดวาง
- script.js  : JavaScript สำหรับลูกเล่น/การทดสอบ

วิธีเปิดดู
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ online_website_project
3. ดับเบิลคลิก index.html เพื่อดูเว็บไซต์ในเบราว์เซอร์

วิธี Deploy ด้วย GitHub Pages
1. สมัครหรือเข้าสู่ระบบ GitHub
2. สร้าง Repository ใหม่ เช่น online-website
3. อัปโหลดไฟล์ทั้ง 4 ไฟล์นี้เข้า Repository (index.html ต้องอยู่ระดับบนสุด)
4. เข้า Settings > Pages
5. ในส่วน Build and deployment เลือก Deploy from a branch
6. เลือก Branch: main และ Folder: /(root) แล้วกด Save
7. รอสักครู่ จากนั้นเปิด URL ที่ GitHub Pages แสดงให้

หมายเหตุ
- เว็บไซต์จะออนไลน์ได้เมื่อ Deploy สำเร็จและบริการโฮสติ้งยังให้บริการอยู่
- GitHub Pages เหมาะกับเว็บไซต์แบบ static (HTML/CSS/JavaScript)
- คำว่าออนไลน์ตลอด 24 ชั่วโมงหมายถึงเข้าถึงได้ตลอดเวลา แต่ไม่มีบริการใดรับประกัน uptime 100%
